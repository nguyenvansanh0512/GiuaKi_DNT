# Danh sách ảnh minh họa cần chụp thật

Tránh chụp URI, `.env`, token, tài khoản database hoặc dữ liệu cá nhân thật. Bật mật khẩu chỉ với mật khẩu giả theo đề. Chèn các ảnh thật vào báo cáo sau khi chụp; chỗ chưa có ảnh phải ghi “Chưa chụp”, không mô tả như bằng chứng đã chạy.
